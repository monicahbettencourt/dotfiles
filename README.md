# Dotfiles

Configuration files for my Linux machines.

## Installation

```bash
git clone https://github.com/<monicahbettencourt>/dotfiles.git
cd dotfiles
./setup
```

The setup script creates symlinks from this repository to the usual dotfile locations (e.g.`~/.bashrc`, `~/.vimrc`, `~/.config/starship.toml`, `~/.tmux.conf`).
